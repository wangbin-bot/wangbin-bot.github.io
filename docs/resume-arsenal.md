# 简历素材总表

本页只收录项目中已经落盘并经过本地检查的技能、项目描述和面试追问点。动态靶场、生产部署、自动封禁和 SOAR 联动只有在实际完成并留存证据后，才可以补充为项目结果。

## 第 02 课：SQL 注入过滤与 PCRE 回溯

### 专业技能关键词

PHP SQL 注入风险分析、PCRE 正则回溯原理、`preg_match` 返回值严格判断、PDO 参数化查询、Python 源码审计、JSONL Web/WAF 日志分析、告警关联与安全回归测试。

### 红队分析 / 代码审计项目描述

围绕 PHP SQL 注入与 PCRE 过滤失效场景，分析用户输入拼接 SQL、`preg_match` 返回值误判等风险，编写 `audit_pcre_filter.py` 本地源码审计工具，输出候选问题的文件与行号，并整理参数化查询及异常默认拒绝的修复方案。

### 蓝紫队检测 / 安全工程项目描述

针对 Web/WAF 日志中的长请求体、SQL 关键词组合、数据库错误和规则命中线索，编写 `analyze_sqli_logs.py` 生成 JSON 告警并支持来源请求计数与人工复核，将检测工具、修复示例和响应流程整理为可构建的课程工程。

### 面试防拷打

重点准备 `preg_match` 的 `1`、`0`、`false` 返回状态、宽松比较的风险、PDO 参数化查询的边界，以及为什么单一关键字规则不能代替代码级修复。
